# متابعة الطالب (نسخة تجريبية)

## بناء الـ APK
### الطريقة 1: Android Studio
1. افتح المجلد بـ Android Studio وانتظر انتهاء Sync.
2. Build > Build Bundle(s) / APK(s) > Build APK(s).
3. الملف: app/build/outputs/apk/debug/app-debug.apk

### الطريقة 2: GitHub بدون تثبيت شيء
1. أنشئ مستودعًا على GitHub وارفع محتوى المجلد.
2. افتح تبويب Actions > Build APK > انتظر النجاح.
3. نزّل app-debug من قسم Artifacts.

البيانات التجريبية في: app/src/main/java/com/school/parent/Data.kt
